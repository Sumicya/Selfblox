# Selfblox

Roblox 执行器脚本：单文件、单面板、七个模块，面向 Delta（安卓）的纯触屏操作。适合在手机上调试移动、载具和显示类功能，并且希望脚本本身可以离线自检的用户。

## 使用

前置条件：安卓设备已安装 Delta 执行器，并允许它读写自己的工作目录（脚本会在该目录写配置、日志和诊断快照，Delta 通常是 `/storage/emulated/0/Delta/workspace/`）。

在执行器里运行：

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Sumicya/Selfblox/HEAD/selfblox.lua"))()
```

地址里的 `HEAD` 跟随仓库默认分支，改默认分支的名字或换默认分支都不用改这一行。重复执行会先自动卸载上一份，手动卸载调用 `_G.SB_UNLOAD()`。执行前可以用 `_G.SB` 覆盖配置，优先级为 `_G.SB` > `Selfblox.json`（面板里改过的值）> 默认值：

```lua
_G.SB = { spd = 60, flyspd = 120, hornkey = "H", only = { "moc", "sibs" } }
```

可覆盖的是数值键、带存盘键的开关和只读配置键（见下表）；速度、飞行、穿墙(人)、秒互动这类没有存盘键的开关，每次执行都从关闭开始。面板里的改动立即生效：开关点一下、下拉循环按一下就写进 `Selfblox.json`，数值要等输入框失焦或回车才写；面板位置和上次页签也在同一个文件里。诊断快照除了「诊断打包」按钮，也可以直接调 `_G.SB_DUMP()`。

使用执行器违反 Roblox 使用条款，可能导致账号受限。脚本按「原样」提供，不作任何保证，风险自负。

## 适用环境与限制

- 目标是 Delta 最新版：`hookmetamethod`、`newcclosure`、`UIDragDetector`、原生 `Highlight` 按一定存在处理；`gethui`、`isfile`、`writefile` 缺失时退回 `CoreGui` 并跳过存盘，面板仍能起来。
- 只有触屏路径，不含键盘和手柄输入。
- 车、漂移、飞机侦察依赖具体游戏的结构（座位、`MobilePedals`、Remote 命名），换游戏可能绑不上。此时用「志」页的「诊断打包」取整机快照，里面已经有 PlaceId、地图名、全部配置、执行器能力、车辆与踏板结构，贴出来即可，不必另外描述环境。
- 穿墙(车)只给本车保留轮胎碰撞：零件名含 `wheel` / `tire` / `tyre` / `轮` 才算轮子。整车一个轮子名都认不到时，退回保留最低的几块（否则车会掉出世界），车页状态行会按实测块数写明，例如「穿墙(车) 开·没认到轮子,按最低块兜底 穿50/留28」。保留的那几块仍然碰撞，所以在零件全是薄板、没有轮子名的游戏里，车看着和没开穿墙一样，这种车用「全穿」一块不留（它靠游戏自己的力撑着走），或者接受保留最低块。
- 穿墙范围是本车所在的容器（往上最多两级的 Model / Folder）里所有没锚定的自由件：同一个容器里的其他车、散件一起不碰（这就是「能穿别人的车」）；锚定的地面、平台、焊死的装饰不碰，地图挡不挡车取决于它在不在这个范围内。轮子没有焊接到车身的游戏会漏穿，漏掉的那块仍然碰撞。车页状态行和「诊断打包」会列出还在碰撞的块、容器里还碰撞的件、以及被游戏改回碰撞的块数，车卡住时先看这几条。
- 绑车不要求车已经解锁：游戏把车锁着（锚定）时照样绑上，提示和状态行写「还锁着(锚定), 等游戏解锁」，解锁后推力自己生效；锁着的是没座位、又不像车（没有轮子 / 座位 / 灯 / 约束）的装饰件时，才会就近改绑到旁边最重的自由件。
- 穿墙(人) 和 穿墙(车) 任意一个开着，都会顺带把其他玩家在本地当成不碰撞：他们的角色全身，以及他们正坐着的载具（整车的非锚定部件）都挡不住你。改的只是自己这一份，服务器和对方客户端都不受影响，他们挡不住你，但仍会被你的车撞开或压过，想推开挡路的人就是这个效果。新加入、刚重生和刚上车的在半秒内补上；我自己也在同一辆车里时不动那辆车（否则会从自己的座位掉下去）。没人开的车和地图照旧挡路，焊在载具上的锚定件也不动。
- 飞机侦察只做侦察：`__namecall` 钩子记录完就原样转发，不拦截也不改参数，脚本本身不发任何飞机 Remote。「收」是拿扫出来的 Remote 列表挂 `OnClientEvent` 的，所以要先点「重扫」，否则「收」永远是 0，看着像服务器没回。收发记录按「同一个 Remote 打同一个目标」折叠成一组并保留首末两条 payload，上限 400 组；不折叠时飞行中每秒约 20 条复制包，200 条只装得下 10 秒，`RequestPlane` 这种一局只发一次的必被挤掉。
- 参数不设人为上限，填错数值可能让角色或载具失控。
- 过弯：弯半径约为速度除以转向速率，速度越高弯越宽。要提高过弯能力就调高 `grip` 和 `turn`，或用 `_G.SB = { turncap = 3 }` 让转向随速度放大（2~4 合适，5 以上会像陀螺）。
- 转向滑条默认放在屏幕左侧、上下居中（底边正中会被手机的返回手势条和游戏自己的按钮吃掉；用 `_G.SB = { steerpos = "bottom" }` 放回底部正中，或 `"right"` 放右侧）。默认折起面板才能拖：面板开着时它压在最低层、不接管触摸（免得跟面板的拖动抢），要面板开着也能拖就开「滑条常可拖」。按住滑条拖（整条轨道任意处都能按）、圆点跟着手指，松手回中、转速归零；有车绑着时它才显示。
- 推力只来自面板上的 `▲ 加速` / `▼ 减速` / `定速`：游戏自己的油门（座位 `Throttle` 或它的踏板）由游戏自己管，我们不再叠一份力 —— 两份力一起推会把车顶得打转，尤其在没别的玩家的服务器里（那时车归你这台机器模拟，我们写的力真的生效；有别的玩家时车多半归服务器，写了也是白写，所以以前看不出问题）。
- 推力**没有任何限速或闸门**：按了加速就一路推，车多快、翻了、横着滑都照推（限速和失控闸都按用户要求撤了）。「诊断打包」里的「驱动」两行会列出：车头与运动方向差多少度、角速度（自己掉头时这两项会露出来）、面板在按什么、游戏油门多大、车姿态 `up.Y`、侧滑、实际推力。
- 抓地力（`grip`）是「速度方向往车头贴」的速率：横滑着跑时，1 约一秒贴掉六成、5 一秒几乎贴直、0 完全不贴（纯漂移手感）。它不只在拖滑条时生效，用游戏自己的方向盘时也在把侧滑掰直，所以调它一定感觉得到（这也是以前调了没感觉的原因：旧版只在用我们滑条打方向时才管）。只在真的在侧滑时动手（侧滑小于 3 格/秒、或直着开时完全不碰速度），单帧最多贴三成，车侧翻/倒扣时不动手 —— 所以直着加速时它一行业都不写，方向乱不会是它。
- 转向松手一定停：拖拽器用 `Scriptable`（引擎只报事件、一个像素都不动 —— 旧版 `TranslateLine` + `BoundingUI` 会让引擎去挪那块和轨道一样大的手柄，挪一次手柄就偏出轨道，轨道其余部分再也按不到，就是「背景不动、只有圆点动」那种怪相）；除了拖拽器的「松手」事件，还自己数着手指 —— 全部抬起就立刻收回转向；而且没手指按着时一律不认拖动事件（引擎残留的拖动事件拐不动车，这是「不按转向、按加速久了车自己掉头」的根）。「诊断打包」里新增的「滑条」一行会写明最近一次按住/松手的位置和时间、现在有几根手指、有没有在拖。
- 车头转速也写进**日志和诊断**（sibs 行的 `车头=+18°/s`，拖着滑条时还有 `滑条=+45%`），1 秒一条的时间线里「自己掉头」一眼看得见；「车头与运动方向差」只在速度 ≥2 格/秒时才量（静止时速度方向是噪声，量出来就是假角度）。
- 车头自己在转时，状态行**一直**写着 `· 车头 +18°/s`（不用开开关、不用打包，直接量车头转了多少，≥3°/s 才显示），拖着滑条时还会带上 `· 滑条 +45%`；谁都没打方向、车却转得超过 15°/s 且持续 0.6 秒，会弹一次提示写明是「滑条没收回去」还是「不是滑条给的转向（游戏物理在这辆车上）」（8 秒内最多一次）。
- 转向有没有生效，看车状态行：转得动就写 `· 转向 62°/s`（实测转速）；拖了滑条车头却不动时写 `· 转向没生效(车不由你这边模拟, 坐进去再试)` —— 车在别人或服务器手里时，客户端写什么都会被顶回来，坐进车里（自己开）才是你的车。「诊断打包」里的「转向自检」一行会同时列出滑条值、命令转速和实测转速。

## 模块与配置键

| 页签 | 模块 | 内容 |
|---|---|---|
| 动 | `moc` | 速度（`root` / `walk` / `cframe` 三种模式）、飞行、高跳、旋转、无限跳、穿墙(人)（角色全身不可碰，顺带本地忽略其他玩家和他们正开的载具）、夜视、秒互动（普通 / 强制）与秒互动距离 |
| 车 | `sibs` | 上车即控；未上车时对准载具按「换车」，按座位锁定所在装配体，打中地图或超大装配体时拒绝绑定（提示里带实测外径和质量，误拒时一眼看得出为什么），进游戏或下车后自动绑最近的空座位。加速、抓地、转向、减速、定速、急刹（在 ▲ 加速 / ▼ 减速 上面，单独一行、行高一致）、穿墙(车)（本车只留轮胎碰撞，本车所在容器里的自由件 —— 别人的车、散件 —— 一起不碰，本地忽略其他玩家和他们正开的载具；保留规则不合适的车用「全穿」连轮子一起穿）、飞车、翻转、灯、喇叭；左侧滑条转向（默认折起面板才能拖，或开 `steeropen`；自己这边模拟的车直接给绕 Y 的角速度 = 真方向盘，轮胎照样抓地、不穿墙；锚定或服务器接管的车只能本地硬转），与游戏自带油门和方向盘同时生效；抓地力一直生效，把侧滑掰回车头 |
| 漂 | `drift` | 人物 `VectorForce` 推进，自动绑定游戏自己的 `MobilePedals`（左刹右油）当油门 / 刹车；面板上只有数值：加速、刹车、摩擦（横向滑动阻尼，0 = 原样） |
| 显 | `hud` | 顶部数据条（延迟、帧率、内存、时间、人数、坐标）、速度箭头、玩家 ESP（原生 `Highlight` 加名牌距离） |
| 志 | `log` | 配置与各模块状态定时追加 `Selfblox_log.txt`，超过上限重写；「诊断打包」把整机快照写进 `selfblox_dump.txt` 并复制到剪贴板 |
| 机 | `plane` | 查找飞机（有座位的、以及只认到机翼名的都算，没座位的残留机也列得出来）、判定队伍、列出 Remote、收发侦听（`__namecall` 钩子）、高亮；报告写 `plane_debug.txt` 并复制到剪贴板，没重扫过就点「写报告」会自动先扫一遍，没过门槛的候选列进「疑似」名单 |
| 砖 | `brick` | BitFarmer 刷砖，开关式 |

|---|---|---|

| `dacc` `dbrake` `dfric` `drift` | 5 10 0 true | 漂移推进：加速 / 刹车 / 摩擦系数（横向阻尼）/ 开关。没有 `MobilePedals` 的游戏只能改数值，推不动 |
| `stats` `arrow` `esp` | true | 数据条 / 速度箭头 / 玩家 ESP |
| `clock` | `12` | 时钟制式，填 `24` 切 24 小时制，数据条和日志都受影响 |

| `pall` | false | 飞机侦察全录 Remote |

## 开发

清单驱动：一个功能等于一个顶层函数加对应页 `do` 块里的一行 `feature{}`，建页、存盘、每帧连接、卸载和诊断快照都由清单生成，核心代码不为新功能改动。控件类型和可用字段见 `selfblox.lua` 里的注册表注释与 `KIND` 表；开关状态在 `F[key]`，数值在 `S[key]`，控件在 `W[key]`。

改完先离线自检，不必上手机：

```bash
lua5.4 smoke.lua   # Termux: pkg install lua54
```

`smoke.lua` 用一个假 Roblox 引擎加载 `selfblox.lua`：建面板、翻每个开关、坐进假车、跑帧、卸载，然后断言状态确实改变、没有报错、卸载后不留实例和连接，并注入一个玩具功能验证清单的扩展性。假引擎对没有核对过官方文档的成员一律抛错，白名单是 `smoke.lua` 里的 `VERIFIED`，逐个对照 create.roblox.com 的引擎 API 参考核对。脚本本体不依赖 `smoke.lua`。

Termux 是设备本地的终端环境，`pkg install lua54` 只安装解释器，不需要 Root，也不改动游戏或系统分区。

## 版本

版本号格式为 `yy.m.d`：两位年份、不补零的月份和日期（Asia/Shanghai 时区）。需要区分同一天内的多次发布时补第四段序号，写成 `yy.m.d.ci`。日期版本不是 SemVer，本仓库不使用 SemVer 字段。

单一来源是 `selfblox.lua` 顶部的 `VERSION`，面板标题、诊断快照和启动打印都读它；展示时不带 `v`，标签为 `v` 加版本号。`smoke.lua` 会检查格式是否合法、三处展示是否一致。

本仓库没有 CI，`ci` 段平时省略；同一天要出第二次就补上，按当天的次数人工递增，从 1 起独立计数，不追溯合并历史标签（远程仍保留旧标签 `v11`，不改名）。当前值 `26.10.3.16` 是 2026-10-03 的第十七版，仅为格式示例，不代表已经发行。没有发行需求时不必为了这个规则打标签或建 Release。发布时把 `VERSION` 改成当次的 `yy.m.d`（同日再发就补 `.<次数>`），提交后打同名标签：

```bash
git tag v26.10.3.16
```
