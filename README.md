# Selfblox v13

一个文件、一个面板、七个模块。Delta（安卓）为目标，纯触屏。

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Sumicya/Selfblox/main/selfblox.lua"))()
```

重跑会自动先卸载；手动卸载 `_G.SB_UNLOAD()`。

## 覆盖参数

执行前设 `_G.SB`，任何键都能覆盖（优先级 `_G.SB` > `Selfblox.json`(面板里改过的) > 默认）：

```lua
_G.SB = { spd = 60, flyspd = 120, hornkey = "H", only = {"moc", "sibs"} }
```

| 键 | 默认 | 说明 |
|---|---|---|
| `only` | 全部 | 只装这些模块 `{"moc","sibs","drift","hud","log","plane","brick"}` |
| `spd` / `spdmode` | 16 / `"root"` | 速度值 / 模式 `root` `walk` `cframe` |
| `flyspd` `jump` `spin` `promptdist` | 50 50 50 1000 | 飞行速度 / 跳力 / 转速(负数反向) / 秒互动距离 |
| `acc` `grip` `turn` `carfly` | 500 5 2.2 60 | 车: 加速度 / 抓地 / 转向速率 / 飞车速度 |
| `turncap` | 1 | 转向速率随速度放大的上限倍数。1 = 原样；2~4 = 越快转得越快，弯半径不再随速度涨（过弯用） |
| `carmaxstuds` | 150 | 多大的 Model 才还算「一辆车」。比这大的容器（整个街区/地图）不再被当成载具 |
| `hornkey` `carclip` | `"H"` false | 喇叭键 / 车穿墙默认开 |
| `dacc` `dbrake` `drift` | 5 10 true | 漂移推进: 加速 / 刹车 / 开关 |
| `stats` `arrow` `esp` | true | 数据条 / 速度箭头 / 玩家 ESP |
| `clock` | `"12"` | 时钟: `12` 小时制(默认) / `"24"` 切 24 小时制, 数据条和日志都吃 |
| `logint` `logmax` | 2 512 | 日志间隔秒 / 上限 KB |
| `pall` | false | 飞机侦察全录 Remote |
| `bbatch` `bint` `bdrain` `bmult` `blevel` | 4 0.08 0.6 99999 9999 | 刷砖参数 |

`hornkey` 没有面板控件（喇叭键在「常声」按钮标题里显示），要改就写在 `_G.SB` 里。
面板里改的数值直接生效并写进 `Selfblox.json`（面板位置、上次页签也在里面）；`显` 页的「复制状态」按钮一键复制整份配置。

## 模块

| 页签 | 模块 | 内容 |
|---|---|---|
| 动 | moc | 速度(3 模式) / 飞行 / 高跳 / 旋转 / 无限跳 / 穿墙 / 夜视 / 秒互动(普通·强制) / 秒互动距离 |
| 车 | sibs | 上车即控(顺手抢网络所有权)；没上车对准载具按「换车」准星锁定。加速·抓地·转向·减速·定速·急刹·穿墙悬浮·飞车·翻转·灯·喇叭；屏幕底部滑条转向(整条能拖、停着也能转)，游戏自带油门/方向盘同时生效 |
| 车·飞车 | sibs | 摇杆前后左右 + 面板「飞 ↑/↓」「▲加速/▼减速」，松手悬停 |
| 车·锁定自愈 | sibs | 锁的那件被游戏换掉 → 按路径自动找回；锁到锚定件（还没解锁/装饰件）→ 自动改绑到 30 格内最重的自由零件；车从锚定变成可动时会提示「车解锁了, 推力生效」。`carswap=false` 关掉自动改绑 |
| 车·开游戏按钮 | sibs | 服务器驱动的车（没座位、客户端推不动）用「选油门/选刹车/选左/选右」把游戏自己的按钮绑上，之后面板「▲加速/▼减速」和滑条 = 直接按游戏按钮（虚拟鼠标事件，按在按钮正中） |
| 车·灯 | sibs | 先接车自己带的灯(SpotLight/PointLight/SurfaceLight，按装配体找，不动别人的车)；车上没灯才装，装车头/车尾部件上，不装座位 |
| 漂 | drift | 人物 VectorForce 推进，自动绑 `MobilePedals`(左刹右油)，没有就用面板按钮 |
| 显 | hud | 顶部数据条(延迟/帧率/内存/时间/人数/坐标) / 速度箭头 / 玩家 ESP(原生 Highlight + 名牌距离) / 复制配置 |
| 志 | log | 配置 + 各模块状态定时追加 `Selfblox_log.txt`，超上限重写 |
| 机 | plane | 找飞机、判队伍、列 Remote、发/收侦听(`__namecall` 钩子)、高亮、报告写 `plane_debug.txt` + 剪贴板 |
| 砖 | brick | BitFarmer 刷砖，开关式 |

## 高速过弯

弯半径 ≈ 速度 ÷ 转向速率（速度 ≥ 25 时转向速率就顶格了）。所以越快弯越宽，想过弯只有两条路：把「转向」拉高，或让转向跟着速度涨。

| 想要 | 抓地 | 转向 | 其他 |
|---|---|---|---|
| 贴地不掉速过弯（轨道型） | 15~20 | 4~6 | 开「定速」，弯中不掉速 |
| 甩尾过弯（漂移型） | 1~2 | 5~6 | 收油，车头先转、速度还朝外 |
| 任何速度都同一个弯半径 | 15~20 | 4~6 | `_G.SB = { turncap = 3 }`，越快转得越快 |
| 转不动（车太重/飘） | +5 一档 | +1 一档 | 先加抓地，再加转向 |

`turncap` 越大越像轨道过弯，5 以上会像陀螺，2~4 是甜点（面板里没有，写 `_G.SB`）。

## 诊断打包

「志」页最上面一个按钮（或代码里 `_G.SB_DUMP()`）：把**整机快照**写进 `selfblox_dump.txt` + 剪贴板，包含——脚本版本、PlaceId/地图名、全部配置、执行器能力（isfile/writefile/setclipboard/gethui/hookmetamethod…）、角色与座位状态、各模块运行时状态、**踏板 UI 完整结构**（名字/类别/可见/可点/位置/尺寸）、**车辆装配体完整结构**（部件名/类别/锚定/质量/尺寸/灯/约束）、日志尾部 1.5KB。

车不听话、踏板绑不上，按一下这个按钮把内容贴出来就够，不用报游戏名、不用报 PlaceId——快照里都有，而且是脚本在你手机里当场 dump 的。

车结构**会缓存最近一辆**——就算点按钮时已经下车了，也能把刚才那辆车的结构带出来；要是已经缓存的那辆被游戏销毁了，快照会直说「已不在 workspace」（不会拿一堆 0 糊弄）。快照里另有：**整个 PlayerGui 树**（每个可见按钮的名字/类/位置/尺寸/**文本**——游戏拿什么开车，一眼看到）、**准星射线打到什么 + 完整祖先链**、**车周围 150 格内的座位**（改用半径扫描，不再被"场景太大只扫前 3 万"截断）、**车周围 25 格里的部件**（不依赖 Model 层级，车的真身）。`selfblox_dump.txt` 落在执行器工作目录（Delta 通常是 `/storage/emulated/0/Delta/workspace/`）。

## 自检

改完代码不用上手机试，离线假引擎跑一遍：

```
lua5.4 smoke.lua        # Termux: pkg install lua54 ; 或用 luajit / lua5.1 / luau
```

它加载 `selfblox.lua`，建面板、翻每个开关、坐进假车、跑 60 帧、卸载，然后断言：开关真的改了状态（速度写进 root、飞行挂了原生约束、车限速抬到无穷、急刹清水平速度）、没报错、**卸载后一个实例一条连接都不剩**，还带一轮 `_G.SB = {only={"moc"}, spd=99}` 的覆盖测试。脚本本体不依赖它。

## v12 → v13

- 只保 Delta 最新版：执行器能力探测（`isfile` `gethui` `newcclosure` `hookmetamethod` `UIDragDetector`）全删，不留兜底；只剩 3 处故意留的 `pcall`（模块隔离、卸载清理、钩子里的记录），以及读 `Selfblox.json` 时防配置损坏
- 车：急刹从"反推力"改成直接把水平速度清零（立刻停，不吃质量）；滑条转向只转游戏自己没转的那部分（`Steer` 相减），不再重复转两次
- 数值控件直接绑表、改完自动存盘，模块不用再各写一份 dump
- `志` 不再让各模块自己拼配置字符串：配置整份 dump，模块只报运行时状态
- UI 加圆角；`秒互动距离`、`排空间隔` 提到面板上；`显` 页加「复制状态」
- 方向盘：钉在屏幕底部（不再动）。**面板开着 = 固定**（不接管触摸、降到最底层、变暗，免得调参数时手一滑把车带跑）；**面板折起来才可拖**（整条背景都能按，圆点跟手，松手回中）
- 标题条：**点一下整条任意位置就折叠**。判定改走拖拽器自己（`DragBegin/DragContinue/DragEnd`）——真机上 `UIDragDetector` 会把标签的输入事件吃掉，之前那套「按了没挪动=点击」在手机上根本不触发，这就是"点了不折叠"的原因；`+/-` 照旧
- 圆角全删；按钮/行之间的间距也全删（`UIListLayout` Padding = 0，行宽不再留 1px）
- 数字输入框文字居中
- 时钟默认 **12 小时制**（`_G.SB = { clock = "24" }` 切回 24），数据条和日志都吃
- 车：**停着也能打方向**；换车提示说人话（打空/打中人/车被锚定分开报）；日志里带上座位名 / 游戏自己的油门·方向值 / 是否锚定，状态行直接标「锚定(等游戏解锁)」
- 车：**滑条常可拖**开关（车页，默认关）——默认仍是「面板折起来才能拖」，折不起来时打开这个就能直接拖
- 车：新增**绑游戏自己的按钮**（油门/刹车/左/右）——服务器驱动的车不吃推力（例如「车没有座位、零件直接吊在 Street 这种大 Model 下」的游戏），只能按游戏自己的按钮开。绑上之后滑条 = 按左/右按钮，不再掰车身
- 车：**载具范围不再爬到地图大容器**——往上找「第一个装着座位的 Model」，找不到就取最近一个「尺寸像车」的 Model，超过 `carmaxstuds`（默认 150）的容器一律不当车。「换车」现在会报出锁定到哪一层、有没有座位（没座位就只推/飞/翻转，不吹牛）
- 车：**不再对锚定的车载具直接放弃**（v13 一锚定就 detach，所以"要动一会才能绑上"）——现在照样挂约束、滑条照样转（走 CFrame），推力等游戏解锁后自动生效
- 车：新增「扫车」按钮，一键把整车结构 dump 到 `selfblox_car.txt` + 剪贴板（部件名/类别/锚定/质量/尺寸/灯/约束），车不听话时贴这个比贴日志有用
- 撤回上一版擅自加的 `SetNetworkOwner(me)`（客户端这一句会把车搞成完全绑不上）
- 漂移踏板：三条路——① 自动找 `MobilePedals`（整个子树找 `GuiButton`，每秒重试、UI 被游戏重建也自动重绑）；② 游戏里没这东西就**自己点选**：「选刹车」「选油门」各按一下，再去点游戏画面上的那个键，按住它就等于踩下（不猜名字、不猜层级，任何游戏都能用）；③ 都没有就用面板按钮。已绑的名字写在「漂」页状态里
- 灯：接车自带的灯；没有才造，且装在车头/车尾部件上（原来装座位，位置离谱）
- 日志里去掉 `ms/fps` 那种备注行，改成模块状态
- 新增 `smoke.lua`（见上），改代码有个东西能兜着
- 保持 Lua 5.4 可解析子集（不用 `+=` / `continue` / 字符串插值），这样自检能离线跑
